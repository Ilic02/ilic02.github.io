# Personal Website

Portfolio site for Nikola Ilić, live at https://ilic02.github.io/

- Plain HTML + CSS, no build step. GitHub Pages serves it straight from `main`.
- Light/dark theme follows the visitor's system setting and remembers their choice.
- The contact form sends messages through [Web3Forms](https://web3forms.com/).

To preview locally: `python3 -m http.server` then open http://localhost:8000
